# Esther Nam Portfolio

Static portfolio site. Plain HTML, CSS, and JS with no build step.

- Pages live at the repo root (`index.html`, `about.html`, and one file per case study).
- Images, GIFs, and videos live in `assets/`.
- Links between pages are relative filenames, so the site works from any folder or host.

To preview locally, open `index.html` in a browser. To publish, enable GitHub Pages on the main branch (root folder).
